# Legacy development artifacts

- `legacy-v2/` preserves the pre-public Router v2.1 plugin and source-oriented build/install scripts.
- The immutable Layman Skill v1 ZIP remains under `dist/` and is copied into every 1.0 release under `legacy/` with its original checksum.

These artifacts are retained for recovery and provenance. They are not public installation entrypoints for Layman 1.0.
