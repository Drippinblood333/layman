# Layman Router v2.1 release candidate

This release candidate productizes the v2 prototype without changing the Layman Skill v1 archive.

Highlights:

- high-risk deep-tier safety floor that metadata and project rules cannot lower;
- varied 300-case routing suite with confusion and throughput analysis;
- resumable, budget-capped real API benchmark with blind quality judging;
- corrected cache-write pricing and honest handling of unknown model prices;
- atomic Codex config writes, post-enable conflict protection and scoped backup restore;
- installation doctor, token generation, telemetry retention and recovery documentation;
- responsive loopback management dashboard with guarded usage APIs;
- package, plugin, privacy and release-candidate validation.

The 2026-07-16 real calibration attempt was rejected before a successful response because the environment API key was invalid. This build therefore remains a release candidate and makes no measured-savings claim.
