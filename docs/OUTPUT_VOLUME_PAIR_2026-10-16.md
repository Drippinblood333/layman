## 解读与下一步

Layman 总 token 比本次 Direct 高 16.43%，观察到的命令输出约为其 7.24 倍。相同操作数下出现不同输出量，说明只统计工具次数不足以定位输出开销；这为后续调查“读取范围/输出体积”提供了实际线索，而不是立即减少工具上限。

但输出字符不是输出 token，也不是后续模型实际收到的完整工具结果。原生 JSONL 可能已截断，MCP/补丁等结果不在本指标覆盖内；内部请求数、历史重发、缓存和模型非确定性仍未被隔离。不能把多出的 18,705 token 全归因于这些命令输出。

缓存不能重复加入总量；未缓存输入本次反而是 Layman 14,549、Direct 19,785。订阅用量不是 API 账单，既不把缓存比例当固定折扣，也不把未缓存输入较少包装成节省结论。

标准分析器返回 `claim_token_savings=false`，仅一个质量/用量合格配对，置信区间未计算。自动验收不替代人工语义判断，不能代表总体质量或长期稳定性。旧批次不补写这两个指标、不合并统计。
