# 离线上下文分解（2026-10-16）

本批确认了新的优化调查方向：继承的技能说明和目录是渲染文本中的主要部分，不能把全部开销归因于 Layman 的执行合约。**没有证明任何 token 节省，没有修改默认提示或删减用户能力。**

## 方法与边界

使用完整匹配的私有 `codex-cli 0.162.0-alpha.20`，执行官方提供的 [`codex debug prompt-input`](https://learn.chatgpt.com/docs/developer-commands#codex-debug-prompt-input)。该命令用于查看构建后的模型可见输入列表；本批没有调用 `exec`、模型或付费 API。

在新的 bugfix-03 合成 Git 工作区中，分别离线渲染同一原始执行任务的 Direct 与 Layman 设置：同一 Sol/medium、OpenAI provider、workspace 权限和 never 审批设置；Layman 加上当前生产合约、输出与压缩配置。未改动全局配置、安装、用户技能或仓库生产源文件。

所有渲染结果只在诊断进程内解析，落盘只保留角色、字符/字节数、SHA-256、已知标记位置和一致性断言。没有保存原始上下文或用户指令内容。合成工作区与诊断脚本、计数位于忽略目录 `build/context-decomposition-2026-10-16/`。

## 已验证结果

按内容块的文本字段计 Unicode 字符，不把 JSON 类型字段或序列化标点算入正文：

| 项目 | Direct | Layman |
| --- | ---: | ---: |
| 渲染消息数 | 5 | 5 |
| 正文字符合计 | 18,083 | 18,829 |
| 原始执行任务字符 | 129 | 129 |
| 共享技能说明与目录块（含标签） | 11,458 | 11,458 |
| Layman 合约及分隔换行的增量 | 0 | 746 |

两项程序断言通过：后四条消息正文逐字相同；Layman 第一条正文恰好等于当前 745 字符合约、一个换行和 Direct 第一条正文。技能说明与目录块约占 Layman 渲染正文的 60.85%；这不是仅技能名称的大小，也不是 token 占比。

两路渲染均退出零且 stderr 为空。诊断脚本仅调用帮助/渲染所对应的 CLI 离线路径，没有模型调用；没有重跑不受影响的产品测试或全平台构建。

## 决定

- 不再把缩短一句执行提示作为主要优化方向。下一项假设应检查技能目录如何被发现与加载、是否能按任务缩小无关目录，同时保留显式点名技能、项目指令和安全约束；先查官方机制，不先实现新的复杂开关。
- 共享技能块同时存在于 Direct 和 Layman，因此其大小**不能解释或抵消**上一批 Layman 多用 26.86% token 的结果。工具轮次、累计历史、缓存和实际工具定义仍需单独分析。
- 该渲染不提供完整实际请求的工具 schema、所有模型内部前缀、后续工具输出或服务端 token 用量。字符不能直接换算 token，更不能据此宣传减少 60.85% 的用量。
- 未验证全局自定义指令是否存在，因此这次差分不能支持“所有用户自定义指令都被保留”的泛化结论。未来缩减策略必须另测这一不变量。
- 没有产品行为变化，没有新增依赖、安装替换、推送或正式发布。长期目标继续保持进行中。
